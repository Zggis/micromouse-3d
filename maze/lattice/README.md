# Lattice Structure

If using the elevated cells, you do not need to print vertices for levels supported by the elevated cells.

![](/../../assets/images/lattice.jpg)

## Print Settings

- Orient the parts on the print bed as they are shown above.

| Setting                 | Value | Reason                                                                                     |
|-------------------------|-------|--------------------------------------------------------------------------------------------|
| Perimeters / Wall Loops | 3     |                                                                                            |
| Infill                  | 15%   | These pieces need to span a gap, the extra infill and perimeters help to prevent drooping. |
| Solid Layers - TOP      | 5     |                                                                                            |

## Assembly

The dovetails in the vertices should face up so the connectors slide down into them.

The connectors should have the insert slot facing up to it can cradle the cell insert and create a flush surface for the robots to travel.

Vertices will have either a support pillar or standard pillar inserted into them depending on if they are on the top or mid-level of the maze.

![](/../../assets/images/lattice_assembled.jpg)

The ramp connector is secured to the ramp using standard pillars.

![](/../../assets/images/ramp_connector.jpg)
